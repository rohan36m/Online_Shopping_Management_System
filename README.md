Developed a full-stack Online Shopping Management System that enables users to browse, search and purchase products seamlessly. 
  The system includes secure user authentication, product management, shopping cart, wishlist, and order tracking features. 
  The frontend was built using React.js, HTML, and CSS for a responsive and interactive user interface, 
  while the backend was developed using Django Rest Framework (DRF) to handle APIs, data management, and authentication.

Key Features:
•	User registration, login, and profile management (JWT authentication)
•	Product listing, category filtering, and search functionality
•	Shopping cart and wishlist management
•	Order placement and tracking system
•	Admin dashboard for product and order management
•	RESTful APIs integration between frontend and backend

Technologies Used:
•	Frontend: React.js, HTML5, CSS3
•	Backend: Django Rest Framework (DRF), Python
•	Database: SQLite 
•	Tools: Visual Studio Code, Postman, Git/GitHub
